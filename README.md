# BMIN5030 Final Project

This repository contains the code for Claire Lai's BMIN 5030 Final Project. This project aims to understand Philadelphia's litter problem to better target public health and sanitation interventions. Litter and neighborhood cleanliness are important social determinants of health that can negatively affect the residents of the city and is an important issue in the city of Philadelphia. 

The datasets contained in this repo are CSV and shape files for the 2017 Philly Litter Index, as well as shape files of Philadelphia planning districts and the 2024 location data of Big Belly Waste Baskets in the city.
